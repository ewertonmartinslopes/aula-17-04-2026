# 🐍 Python – Estruturas Condicionais (`if`, `elif` e `else`)

Este repositório reúne atividades desenvolvidas no **Google Colab** com foco na utilização das **estruturas condicionais** da linguagem Python.

Os exercícios exploram situações práticas do cotidiano, permitindo desenvolver programas capazes de tomar decisões com base nas informações fornecidas pelo usuário, utilizando operadores relacionais e lógicos.

---

## 🎯 Objetivos do Projeto

* Compreender o funcionamento das estruturas condicionais.
* Desenvolver programas capazes de tomar decisões.
* Praticar operadores relacionais e lógicos.
* Trabalhar com entrada e processamento de dados.
* Simular situações reais utilizando regras de negócio.

---

## 📚 Atividades Desenvolvidas

### 🔹 Atividade 1 – Verificação de Maioridade

Programa que solicita a idade do usuário e informa se ele é **maior** ou **menor de idade**.

Foi utilizada a estrutura `if` juntamente com `else` para realizar a decisão.

**Conceitos praticados:**

* Entrada de dados (`input`)
* Conversão para inteiro (`int`)
* Estruturas condicionais
* Operadores relacionais

---

### 🔹 Atividade 2 – Situação Eleitoral

Programa que analisa a idade informada e identifica a situação do eleitor.

As regras utilizadas foram:

* Menor de 16 anos → Menor de idade
* Entre 16 e 17 anos → Voto opcional
* Entre 18 e 75 anos → Voto obrigatório
* Demais casos → Nenhuma das opções

Foi utilizada a estrutura `if`, `elif` e `else`.

**Conceitos praticados:**

* Estruturas condicionais encadeadas
* Operadores relacionais
* Operadores lógicos (`and`)
* Regras de decisão

---

### 🔹 Atividade 3 – Cálculo de Bônus por Meta

Programa que calcula o bônus de um vendedor conforme o valor das vendas e as metas estabelecidas.

Regras implementadas:

* Atingindo a meta principal → bônus de 10%.
* Superando a meta superior → bônus de 13%.
* Não atingindo a meta → sem bônus.

**Conceitos praticados:**

* Estruturas condicionais
* Operadores matemáticos
* Operadores relacionais
* Regras de negócio
* Cálculos com porcentagem

---

### 🔹 Atividade 4 – Tipo de Entrega

Programa que identifica o tipo de entrega informado pelo usuário.

As opções disponíveis são:

* Entrega padrão
* Entrega expressa

Caso seja informado um valor diferente, o programa exibe uma mensagem de opção inválida.

**Conceitos praticados:**

* Comparação de strings
* Estruturas condicionais
* Validação de entrada
* Tomada de decisão
